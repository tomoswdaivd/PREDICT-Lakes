# AGENTS.md

PREDICT-Lakes supports lake forecasting and analysis for the PREDICT project.

## Project conventions

- Python and Jupyter are the main tools.
- Never modify raw data.
- Store large or raw datasets under `data/`; do not commit them to the repository.
- Keep notebooks reproducible.
- Put reusable analysis code in `src/`.
- Put generated results in `outputs/`.
- Keep changes small, explicit, and scientifically interpretable.
